## 诊断标准

### 修订版 El Escorial 标准（Airlie House, 1998）

| 级别 | 定义 |
|------|------|
| **Definite ALS（确诊）** | 球部 + 至少2个脊髓区域（颈/胸/腰）或 3个脊髓区域的上+下运动神经元体征 |
| **Probable ALS（很可能）** | 至少2个区域的上+下运动神经元体征 |
| **Probable ALS - Lab Supported** | 1个区域 + EMG证据 + 排除其他诊断 |
| **Possible ALS（可能）** | 1个区域的上下运动神经元体征 |

**辅助检查**：
- 肌电图/神经传导速度（EMG/NCS）：广泛神经源性损害，无传导阻滞
- 头/颈椎MRI：排除结构性病变
- 实验室：排除MMN、SBMA、CIDP等类似疾病
- 基因检测：C9orf72 + SOD1 作为一线检测

## 呼吸管理

### 监测频率
- FVC > 80%：每3个月
- FVC 50-80%：每1-2个月
- FVC < 50%：每月

### NIV启动指征（满足任一即可）
1. FVC < 50% 预测值
2. 坐位到卧位FVC下降 > 20%
3. SNIP（鼻吸气压）< 40 cmH₂O
4. 日间高碳酸血症（PaCO₂ > 45 mmHg）
5. 夜间低通气症状（晨起头痛、日间嗜睡、睡眠质量差）

### NIV优化
- 目标：IPAP使潮气量达6-8 mL/kg
- 备机：备用呼吸机以防故障
- 咳嗽辅助：MI-E（机械吸呼气）设备当峰咳流速<270 L/min

### 气管切开
- 在充分告知后进行（属于有创通气）
- 需考虑患者意愿、家庭支持、长期护理能力

## 营养管理

### 监测
- 每次就诊称重
- 每3个月评估吞咽功能（VFSS/FEES）
- 每3-6个月查血白蛋白/前白蛋白

### PEG指征（满足任一）
1. 体重下降 > 10%（从病前体重）
2. BMI < 18.5
3. 进食时间 > 30分钟/餐
4. 反复误吸或吸入性肺炎
5. 脱水或营养不良

### PEG时机
- **安全窗口**：FVC > 50%（并发症<10%）
- **高风险**：FVC < 50%（并发症可达50%）
- FVC < 50%时建议在NIV支持下进行，或考虑RIG（放射学引导下胃造瘘）

## 随访计划

| 频率 | 评估内容 |
|------|----------|
| 每1-3月 | ALSFRS-R、FVC、体重、症状回顾 |
| 每3月 | MDT综合评估（神经科/呼吸科/营养/康复/心理） |
| 每月（晚期） | FVC、血气、NIV依从性、PEG护理 |

## 临终关怀

- **提前护理计划（ACP）**：在呼吸功能尚好时讨论
- **预立医疗指示（AD）**：明确是否接受气管切开/有创通气
- **安宁疗护**：控制疼痛、呼吸困难、焦虑
- **吗啡/苯二氮卓类**：缓解终末期呼吸困难
- **心理支持**：患者及家属

## 关键建议总结

1. 多学科管理优于单一专科管理（A级证据）
2. 利鲁唑100mg/天适用于所有确诊ALS患者（A级证据）
3. NIV延长生存、改善生活质量（B级证据）
4. PEG应在体重显著下降前进行（B级证据）
5. 早期沟通临终意愿改善终末期体验（C级证据）
