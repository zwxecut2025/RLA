## ALS 遗传学概览

- **家族性ALS（fALS）**：约10%，通常为常染色体显性遗传
- **散发性ALS（sALS）**：约90%，无明确家族史
- **已知基因**：超过40个，最常用panel检测约20-30个
- **检测推荐**：所有ALS患者均应提供C9orf72 + SOD1检测（EFNS指南）

## C9orf72 — 最重要的ALS基因

| 特性 | 详情 |
|------|------|
| 变异类型 | GGGGCC六核苷酸重复扩增（正常<30，致病>数百） |
| fALS占比 | 30-40%（欧美人群最高） |
| sALS占比 | 5-7% |
| 遗传模式 | 常染色体显性 |
| 典型表型 | 球部起病多见，进展快，高FTD合并率 |
| 中位生存 | 约24个月（非携带者约36个月） |
| 机制 | C9orf72蛋白功能丧失 + RNA foci毒性 + DPR毒性 |

**临床提示**：C9orf72携带者家属有50%遗传风险，应提供遗传咨询。

## SOD1 — 第一个被发现的ALS基因（1993年）

| 特性 | 详情 |
|------|------|
| 变异类型 | 错义突变为主（>180种已知突变） |
| fALS占比 | 约20% |
| sALS占比 | 1-2% |
| 遗传模式 | 常染色体显性（少数隐性） |
| 典型表型 | 下肢起病多见，A4V极快/H46R极慢 |
| 整体中位生存 | 约2.7年（A4V仅1.2年，非A4V约6.8年） |
| 靶向治疗 | **Tofersen**（ASO反义寡核苷酸，FDA加速批准2023年） |

**关键**：SOD1-ALS是目前唯一有获批基因疗法的ALS亚型。

## TARDBP（TDP-43）

| 特性 | 详情 |
|------|------|
| 变异类型 | 错义突变 |
| fALS占比 | 3-5% |
| 典型表型 | 上臂起病多见，进展中等 |
| 病理意义 | TDP-43蛋白异常聚集是97% ALS的共同病理特征 |

## FUS

| 特性 | 详情 |
|------|------|
| 变异类型 | 错义突变（P525L最严重） |
| fALS占比 | 3-5% |
| 典型表型 | 青少年起病，进展快，亚洲人群中较多见 |
| 特殊表现 | 部分FUS突变导致早发型ALS（<25岁） |

## TBK1

| 特性 | 详情 |
|------|------|
| 变异类型 | 功能丧失突变 |
| fALS占比 | 1-3% |
| 典型表型 | 可伴额颞叶痴呆 |
| 机制 | 自噬通路缺陷 |

## 基因检测结果的临床解读

- **致病性(P)/可能致病性(LP)**：明确致病，家属建议进行级联检测
- **意义不明(VUS)**：不确定，定期重新评估
- **良性(B)/可能良性(LB)**：非致病性
- **野生型/阴性**：未检测到已知致病变异，但不能排除未知基因
