## 特征贡献解读方法

### 基本公式

每个特征的贡献值 = β × (X - X₀)

其中：
- β = 该特征的模型系数（ln(HR)）
- X = 该患者该特征的实际值
- X₀ = 该特征的参考值（通常为0或人群均值）

贡献值 > 0 → 增加风险 → 缩短预测生存期
贡献值 < 0 → 降低风险 → 延长预测生存期

### 贡献分解示例

对于一名典型患者（52岁/球部起病/ΔFS=1.96/FVC=47%/诊断延迟8月/野生型/男性）：

| 特征 | β | 实际值(X) | 参考值(X₀) | 贡献值 | 方向 |
|------|---|----------|-----------|--------|------|
| FVC (per 10%) | -0.121 | -5.3 | 0 | +0.64 | ⬆ 增风险 |
| ALSFRS-R斜率 | +0.392 | 1.95 | 0.5 | +0.57 | ⬆ 增风险 |
| 球部起病 | +0.300 | 1.0 | 0 | +0.30 | ⬆ 增风险 |
| C9orf72+ | +0.372 | 0 | 0 | 0 | — |
| 年龄(per 10yr) | +0.296 | 0 | 0 | 0 | — |
| SOD1+ | +0.182 | 0 | 0 | 0 | — |
| 男性 | +0.049 | 1.0 | 0 | +0.05 | ⬆ 增风险 |
| 诊断延迟(per mo) | -0.025 | 8.0 | 0 | -0.20 | ⬇ 减风险 |

**总log-HR** = 0.64 + 0.57 + 0.30 + 0 + 0 + 0 + 0.05 + (-0.20) = **1.36**

这表示该患者的死亡风险是参考患者的 exp(1.36) ≈ 3.9 倍。

### 如何向患者解释

> "您的预测生存期主要是基于三个因素：**较快的功能下降速度**（最大的影响）、**较低的肺活量**、以及**球部起病**。同时，**疾病诊断较早**（8个月延迟）对您来说是一个有利因素，部分抵消了前面的风险。"

### 特征可干预性

| 特征 | 可干预性 | 干预措施 |
|------|---------|----------|
| FVC | ✅ 可部分干预 | NIV、呼吸训练 |
| ALSFRS-R斜率 | ✅ 可部分干预 | 药物治疗、康复 |
| 球部起病 | ❌ 不可干预 | 对症管理 |
| 年龄 | ❌ 不可干预 | — |
| 基因 | ❌ 不可干预 | 靶向治疗（SOD1） |
| 性别 | ❌ 不可干预 | — |
| 诊断延迟 | ❌ 不可干预 | — |
