## 疾病修饰药物（DMT）

### 1. 利鲁唑（Riluzole）— 1995年获批

| 特性 | 详情 |
|------|------|
| 机制 | 谷氨酸释放抑制剂，降低突触间隙谷氨酸浓度 |
| 剂量 | 50mg 口服 每日两次 |
| 疗效 | 延长中位生存约2-3个月（首个获批的ALS药物） |
| 副作用 | 乏力、恶心、肝酶升高（需监测ALT） |
| NNT | 约10（需治疗10人延长1人生存） |

**推荐**：所有ALS确诊患者均应使用，除非有禁忌症。

### 2. 依达拉奉（Edaravone）— 2017年获批

| 特性 | 详情 |
|------|------|
| 机制 | 自由基清除剂，减轻氧化应激损伤 |
| 剂量 | 60mg 静脉输注，每日一次，14天/月 |
| 纳入标准 | 病程≤2年、FVC≥80%、ALSFRS-R各项≥2分、ΔFS不太快 |
| 疗效 | 减缓ALSFRS-R下降约33%（在特定亚组中） |
| 副作用 | 头痛、注射部位反应、偶见过敏 |

**推荐**：早期ALS患者（符合纳入标准者）考虑使用。快速进展者获益有限。

### 3. 托弗森（Tofersen）— 2023年FDA加速批准

| 特性 | 详情 |
|------|------|
| 机制 | 反义寡核苷酸（ASO），靶向降解SOD1 mRNA |
| 适应症 | **仅SOD1突变**ALS患者 |
| 给药 | 鞘内注射（腰椎穿刺），每12周一次 |
| 疗效 | 降低血浆NfL水平60%，减缓临床进展 |
| 副作用 | 头痛、背痛、CSF白细胞升高 |

**关键**：首个针对ALS遗传亚型的精准治疗。SOD1患者应在确诊后尽快做基因检测。

## 非药物干预 — 延长生存的核心

### 无创通气（NIV）

- **启动阈值**：FVC < 50% 或 出现高碳酸血症症状（晨起头痛、日间嗜睡）
- **参数**：BiPAP S/T模式，IPAP 10-14 cmH₂O，EPAP 4-6 cmH₂O
- **获益**：延长生存约7个月，改善生活质量
- **推荐**：所有FVC<50%的患者应开始NIV

### 经皮胃造瘘（PEG）

- **适应症**：体重下降>10%、进食时间>30分钟、反复误吸
- **时机**：FVC > 50%时进行更安全（FVC < 50%时并发症风险增加）
- **获益**：改善营养，稳定体重，可能延长生存
- **推荐**：在呼吸困难加重前进行预防性PEG

### 多学科综合管理（MDT）

- **团队**：神经科医生 + 呼吸科 + 营养师 + 康复师 + 言语治疗师 + 社工
- **频率**：每3个月一次MDT评估
- **获益**：延长生存约6-12个月（综合效应）

## 对症治疗

| 症状 | 治疗选择 |
|------|----------|
| 流涎 | 阿米替林、东莨菪碱贴片、肉毒素注射 |
| 假性球麻痹（强哭强笑） | 右美沙芬/奎尼丁 |
| 肌肉痉挛 | 巴氯芬、替扎尼定 |
| 便秘 | 乳果糖、聚乙二醇 |
| 疼痛 | 加巴喷丁、非甾体抗炎药 |
| 焦虑/抑郁 | SSRI类抗抑郁药 |
| 失眠 | 佐匹克隆、褪黑素 |
